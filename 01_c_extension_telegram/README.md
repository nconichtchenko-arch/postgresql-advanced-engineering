# PostgreSQL C Extension: Telegram Sender

## 🎯 О задаче
Это была **дополнительная лабораторная работа повышенной сложности**. Задача — написать расширение для PostgreSQL на языке C, которое позволяет отправлять сообщения в Telegram API напрямую из SQL-запросов. 

## 🛠 Инженерный вызов
Задача требовала:
1. Использования `libcurl` для отправки HTTP POST-запросов.
2. Динамической загрузки библиотек (`dlopen` / `dlsym`), так как C-код должен компилироваться и работать внутри среды PostgreSQL.
3. Сборки через `PGXS` (PostgreSQL Extension Build System).
4. Развертывания окружения в Docker (Ubuntu + PostgreSQL 16 + зависимости для сборки).

## 📂 Файлы проекта
*   `pg_tg_sender_onionctchenko.c` — исходный код функции на C.
*   `Makefile` — скрипт для сборки расширения.
*   `.control` и `.sql` — метаданные и регистрация функции в базе.

## ✅ Результат
Расширение успешно скомпилировано и установлено в PostgreSQL. Вызов функции `send_to_telegram()` из SQL отправляет реальное сообщение в Telegram-чат.
