# Построение иерархий в SQL (Рекурсивные CTE)

## 🎯 Задача
Спроектировать базу данных для управления проектами (сотрудники, роли, менеджеры) и реализовать функцию `getHierarchy()`, которая строит дерево подчиненности (от лидера проекта до рядовых разработчиков).

## 🛠 Решение
Задача решена с использованием **рекурсивного CTE** (`WITH RECURSIVE`). Функция возвращает имя сотрудника, его роль, уровень в иерархии и полный путь от лидера (например, `Сергей -> Ильяс -> Иван`).

В рамках работы были реализованы и сравнены **4 варианта** функции:
1.  **Рекурсивный CTE** (Выбран как оптимальный по производительности и читаемости).
2.  Подзапросы и агрегация (Подходит для БД без поддержки рекурсии).
3.  Временная таблица (PL/pgSQL).
4.  Функция с циклами и условиями (PL/pgSQL).

## 📊 Вывод
Рекурсивный CTE является стандартом де-факто для обхода иерархических структур в PostgreSQL. Он лаконичен, легко поддерживается и показывает высокую производительность по сравнению с итеративными подходами на PL/pgSQL.
