# PostgreSQL Advanced Engineering & Research

Данный репозиторий содержит инженерные кейсы и исследования архитектуры PostgreSQL, выполненные в рамках профессиональной переподготовки (Университет Иннополис). 

Здесь собраны задачи, выходящие за рамки стандартного SQL: от написания C-расширений до нагрузочного тестирования и проектирования Data Vault.

## 🔬 Исследовательские кейсы:

### 1. [PostgreSQL C Extension: Telegram Sender](./01_c_extension_telegram)
Разработка низкоуровневого расширения на языке C для интеграции PostgreSQL с Telegram API.
*   **Стек:** C, `libcurl`, PGXS.
*   **Особенность:** Динамическая загрузка библиотек (`dlopen`/`dlsym`), сборка через Makefile.

### 2. [Моделирование данных: Data Vault, EAV и Битемпоральность](./02_data_modeling)
Проектирование сложных моделей данных для корпоративных хранилищ (DWH).
*   **Стек:** SQL (DDL).
*   **Особенность:** Использование паттерна Data Vault (Hub, Satellite, Link) и гибридной EAV-модели с отслеживанием истории (битемпоральность).

### 3. [Построение иерархий в SQL (Рекурсивные CTE)](./03_recursive_cte)
Создание функции для построения дерева подчиненности сотрудников с помощью `WITH RECURSIVE`.
*   **Стек:** SQL, PL/pgSQL.
*   **Особенность:** Сравнительный анализ 4-х подходов к реализации иерархии (CTE, подзапросы, временные таблицы, циклы).

### 4. [Анализ производительности: VIEW vs Table (Нагрузочное тестирование)](./04_view_performance)
Проверка мифа о медленной работе VIEW с помощью утилиты `pgbench`.
*   **Стек:** PostgreSQL, `pgbench`, `EXPLAIN ANALYZE`.
*   **Особенность:** Тестирование на 10 млн строк, 90 клиентов, доказательство эффективности кэширования планов запросов.
